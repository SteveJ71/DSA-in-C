# DSA-in-C

Data structures and algorithms implemented in C. A practice and reference library with clear, minimal implementations and runnable demos.

See [RUNNING-C-CODE.md](RUNNING-C-CODE.md) for compilation, debugging, and memory checking setup (gcc, Valgrind, AddressSanitizer).

---

## Repository Structure

### `exercises/`
Small, focused programs covering fundamentals and classic problems.

| Topic | Description |
|-------|-------------|
| c-fundamentals | Pointers, structs, heap allocation, memory management |
| sorted-linked-list | Sorted insertion into a linked list |
| int-queue | Queue ADT (static array) |
| insertion-sort | Insertion sort implementation |
| fibonacci | Recursive and iterative fibonacci |
| euclidean-gcd | Greatest common divisor |
| subset-sum | Backtracking subset sum |
| pair-with-sum | Find pairs summing to target |
| prefix-averages | Prefix average algorithms |
| collatz | Collatz conjecture sequence |
| decimal-to-binary | Base conversion |
| monte-carlo | Monte Carlo estimation |
| curve-length | Numerical curve length |
| vector-inner-product | Vector dot product |
| heterogram | Heterogram check |
| make10-game | Make 10 puzzle |
| randword | Random word generation |
| time-complexity | Big-O demonstration |

### `projects/`
Larger, multi-file implementations with headers, separate compilation, and tests.

| Project | Description |
|---------|-------------|
| binary-search-tree | BST with insert, delete, search, height, rotations, root insertion |
| balanced-bst | Red-Black Tree with colour-based rebalancing |
| dijkstra | Dijkstra's shortest path with priority queue |
| graph-traversal | DFS and BFS traversal |
| graph-algorithms | Graph algorithm implementations |
| bracket-matching | Stack-based bracket validation |
| string-search | String search algorithms |
| popularity-rank | Ranking algorithm |
