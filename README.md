# DSA-in-C

A personal learning repository containing **data structures and algorithms implemented in C**.

This repository is intended as a **practice and reference library**, focusing on clear, minimal implementations of common data structures and algorithms, along with small runnable demos and tests.

No university assignment prompts or course materials are included — all code is organised and documented independently.
